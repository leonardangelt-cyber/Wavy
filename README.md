# Wavy

Musikplayer für Android (Kotlin, Jetpack Compose, Media3) im Material 3 Expressive / Material You Design.

- Startseite: alle Songs auf dem Handy (Audio + MP4) mit Cover
- Playlists: Songs gruppieren, pro Playlist "Nicht auf Startseite abspielen"
- Player: Cover, wellenförmiger Zeitstrahl, Zurück/Play/Weiter, Shuffle, Wiederholung (aus/immer/einmal), Songtext
- Songtexte werden im Hintergrund von lrclib.net geladen und lokal gespeichert
- Farben des Players passen sich dem Cover an

Build: GitHub Actions (`.github/workflows/build.yml`) -> Artifact `Wavy-debug-apk`.
